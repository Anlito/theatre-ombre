Ce navigateur ne peut pas ouvrir un dossier : utilisez Chrome ou Edge pour le suivi en direct, ou importez les fichiers .json (tous sélectionnés d’un coup avec Ctrl+A).

Ou glissez ici les fichiers .json des équipes (n’importe où dans la page).

  • Les fichiers sont lus dans ce navigateur : rien n’est envoyé ni enregistré sur le site.
  • La note réunit les exercices de programmation (travail enregistré : réussites, indices, vérifications ratées) et votre grille D1 à D7, évaluée sur quatre niveaux dans l’onglet où chaque livrable se corrige : voir « Barème ».
  • Les fichiers des équipes ne sont jamais modifiés. Seuls sont écrits dans le dossier d’une équipe, quand vous le demandez : validations.json (validations ◆, que les élèves voient dans leur carnet) et les photos prises dans « Croquis et dessins ».

    Barème de la note

    Pour chaque exercice : réussi = tous ses points, moins des retenues d’autonomie (indices ouverts et essais ratés avant la réussite) ; commencé sans réussir = une part des points ; non commencé = 0. Les exercices 1 et 2 (entraîner l’IA) ne sont pas notés automatiquement : l’IA se juge avec D4. Les choix et les niveaux sont conservés sur ce navigateur. Exportez une sauvegarde pour les retrouver sur un autre poste.

    Cochez « Noter » pour choisir ce qui compte. Un coefficient nul signifie « Non noté ». Les livrables D1 à D7 se notent sur quatre niveaux (Non atteint · Partiellement atteint · Atteint · Dépassé), dans l’onglet où chacun se corrige ; un livrable pas encore évalué reste hors du total.
